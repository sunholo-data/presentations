One command. The PDF always matches the talk.

The command is node export-pdf.mjs death-by-powerpoint --density=guide. A normal print can’t do this, because the slides animate in. So the script opens the real deck in Chrome and takes a picture of each finished slide. Whoever asked for the slides gets them, plus what I said.
