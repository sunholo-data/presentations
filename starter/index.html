Copy this prompt

Follow the attached presentation guide and template. Create a six-slide HTML presentation about [topic] for [audience]. The audience should leave knowing [key message]. Use these facts and sources: [paste your material]. Return one HTML file I can download and open in a browser.

Continue in the same chat: “Make slide 3 simpler”, “Use our brand colours”, or “Add a comparison using these figures.” Attach your logo or images if you want to include them.

Before you present: check the facts, click through every slide and try both themes. Uploads, downloads and code execution depend on your AI product and account. This starter has been checked as an HTML template; the full workflow has not yet been tested in all three products. The optional checker can run only where code execution is available, and it does not replace a visual review. Fonts and icons use public CDNs; the deck has system-font fallbacks.

Use it again

Keep the same chat for revisions. For recurring work, save the starter as reference material in a project if your AI tool supports it.
